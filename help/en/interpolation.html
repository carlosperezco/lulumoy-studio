Interpolation and borders

Geometric transforms look up each output pixel at a position (x, y) of the original image that is almost never an integer. Interpolation estimates the value there from the neighbouring pixels.

Empty areas (borders)

When the position falls outside the original image: Black uses 0; Repeat edge uses the nearest edge pixel (aaa|abcd|ddd); Mirror reflects the image at the edge (cba|abcd|dcb).
